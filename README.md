# Tessa-ripple

Tessa-ripple is a program that manipulates the vertex locations of 3D objects by encoding their coordinates into a quantum computer.

## Overview

A 3D object is defined by its vertices, each with an (x, y, z) position. Tessa-ripple encodes those coordinates into the state of a quantum computer, applies quantum operations to change them, and reads the results back out as new vertex positions.

## How it works

1. **Load** a 3D object and extract its vertex coordinates.
2. **Encode** the coordinates into a quantum computer.
3. **Manipulate** the encoded vertices with quantum operations.
4. **Decode** the measured results back into vertex locations to produce the modified object.
